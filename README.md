# Descripción
Programar en C puede ser tedioso cuando no se tiene acceso a las funciones estándar
más utilizadas. Este proyecto tiene como objetivo ayudarte a comprender cómo actuán
estas funciones, implementarlas por tu cuenta y aprender a utilizarlas de forma eficaz.
Desarrollarás una librería propia que te será muy útil en los próximos proyectos de C.
Asegúrate de ir enriqueciendo tu libft a lo largo del cursus. Sin embargo, cuando
la utilices, asegúrate de que todas las funciones empleadas por tu librería respetan las
permitidas por cada proyecto.
